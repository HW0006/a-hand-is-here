# Charity Care Navigator

Interactive demo of an AI chatbot that screens patients for hospital financial
assistance and auto-fills their application in real time, based on the 2024
HHS Federal Poverty Guidelines.

## Run it

```bash
npm install
npm run dev
```

## Design

The palette is built on orange/peach/brown tones (light mode background
`#f4b690`, dark mode background `#372819`, accent `#e9955a` / `#f0b48c`).
Orange-brown hues sit on the blue-yellow axis rather than the red-green axis,
which makes this palette one of the friendlier color choices for people with
red-green color blindness (deuteranopia/protanopia, the most common forms) —
unlike palettes that rely on distinguishing red from green to convey meaning.
